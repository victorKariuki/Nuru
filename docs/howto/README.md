# Nuru How-To: Modular Learning Units

Topic-based guides with learning outcomes and explained examples. They follow a **computer-science style curriculum** (environment → values → control flow → abstraction → data structures → I/O → text/time → numerics → networks → system). For full syntax and API reference, see the [language documentation](../../repl/docs/en/README.md) (and [Kiswahili](../../repl/docs/sw/)).

**Full curriculum (all units the codebase can support):** [UNITS_SUPPORTED_BY_CODEBASE.md](UNITS_SUPPORTED_BY_CODEBASE.md) — reference docs, examples, prerequisites, and CS1 / CS1+ / CS2-style tiers.

## Units by part

| Part | Theme | Unit | Topic | Status |

| 6 | Text and time | 6.1–6.2 | Regular expressions, Time | *Planned* |

**Suggested course tiers:** *CS1 core* = Parts 0–4. *CS1+* = add Parts 5–6. *CS2-style* = Parts 7–9. See [UNITS_SUPPORTED_BY_CODEBASE.md](UNITS_SUPPORTED_BY_CODEBASE.md#curriculum-map-at-a-glance).

## For teachers

Each unit lists **learning outcomes** and **examples** with short commentary. No exercises are included; add your own tasks or point learners to the inline examples. Follow the part/unit order for a linear syllabus, or pick units by prerequisite (see the curriculum doc).

## For self-learners

Start with [Getting started](00-getting-started.md) (0.1), then follow the curriculum or jump to topics you need. Use the **Reference** links at the end of each unit for full API details.
